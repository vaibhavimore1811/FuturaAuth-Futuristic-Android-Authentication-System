# 📖 Overview

**FuturaAuth** is a premium futuristic Android authentication application built using **Java** and modern Android UI technologies.

The project showcases a high-end authentication experience with:

- 🔐 Secure Login & Registration
- 📩 OTP Email Verification
- 🎬 Cinematic Screen Transitions
- ✨ Glassmorphism UI Effects
- 🌌 Neon Cyberpunk Aesthetics
- ⚡ Real-Time Validation

# ⚙️ Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/yourusername/FuturaAuth-Android.git
```

## 2️⃣ Open in Android Studio

Use:

- Android Studio Giraffe or newer

---

## 3️⃣ Add Animation Files

Place your Lottie animation JSON files inside:

```bash
app/src/main/res/raw/
```

---

## 4️⃣ Sync Gradle

```bash
File → Sync Project with Gradle Files
```

---

## 5️⃣ Run the Application

- Connect Android device OR emulator
- Click ▶ Run
